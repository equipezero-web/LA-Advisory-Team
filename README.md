# L&A Advisory Team

Sistema interno de gestão e comunicação da equipe L&A Advisory.

## Módulos planejados
- Dashboard executivo Glassy Dashboard V5
- CRM/Kanban: Contatos → Em negociação → Desenvolvimento → Fechados → Mensalistas
- Cadastro de clientes, observações e histórico
- Projetos e tarefas
- Financeiro, faturamento e receita recorrente
- TikTok Analytics e monetização
- FlowBoost: pedidos e faturamento
- Comunicação interna da equipe
- Login, perfis e permissões
- PWA instalável em celular e computador

## Identidade visual
Interface premium inspirada na referência Glassy Dashboard V5 fornecida para o projeto: superfícies translúcidas, blur, fundo institucional visível, navegação compacta e destaques em dourado seguindo a identidade L&A Advisory.
